# Digital Notice Board — MERN Stack

Full-stack Digital Notice Board web application built using MERN stack.

## Tech Stack
- React JS (Frontend)
- Node.js + Express (Backend)
- MongoDB Atlas (Database)
- JWT Authentication
- bcrypt password hashing

## Features
- User registration & login
- Encrypted password storage
- JWT authentication
- Create, Read, Update, Delete notices
- Protected dashboard routes
- Form validation
- MongoDB data storage

## Project Structure
frontend — React UI  
backend — Express API + MongoDB

## Run Locally

### Backend
cd backend  
npm install  
npm run dev  

### Frontend
cd frontend  
npm install  
npm start
